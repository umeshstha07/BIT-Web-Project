# Umesh Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in your browser.

## Personalize before publishing
- Replace `Umesh` and the sample biography with your own details.
- Update the education and project descriptions to reflect your real experience.
- Replace `your.email@example.com` in `index.html` and `script.js` with your email.
- Add real social links and project URLs if you have them.

## Contact form
The form uses a `mailto:` link to prepare an email in the visitor's email app. It does not send messages directly or store submissions. For a production contact form, connect a backend or form service.

## Publish
You can host these three files on GitHub Pages, Netlify or any static web host.
